# SEE AMERICA / WHITE SANDS

Independent student research presentation. The live site plays a timed sequence and supports manual exploration. Its companion PDF is a static research document.

## Publish
Create a public GitHub repository named `see-america-white-sands`, upload the **contents** of this folder to its root, and enable Settings → Pages → Deploy from a branch → `main` / `(root)`. The expected URL is `https://brookehoward2008-droid.github.io/see-america-white-sands/`, but confirm the actual published URL before using it in the PDF.

## Research and rights
Images `assets/nps-*.jpeg` were extracted from the user-supplied White Sands research PDF, with NPS attribution as stated there. Verify each original NPS image record and rights before public publication. The site is a working study, not an NPS publication.

## Quality gates
1. Verify all image source records and factual claims.
2. Test playback, pause, restart, keyboard, and reduced motion on desktop and iPhone.
3. Review line wrapping and image crop at 375px, 768px, 1440px.
4. After deployment, update the research PDF with the confirmed public URL.
