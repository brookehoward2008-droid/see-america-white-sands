# SEE AMERICA — WHITE SANDS

Research presentation about White Sands National Park, New Mexico.

## Production intent
- Authentic, licensed photography and documentary research.
- Cinematic auto-playing HTML/CSS/JavaScript presentation with restrained parallax.
- Accessible manual exploration and reduced-motion support.
- Companion research PDF with a link to the published site.
- No poster production in this phase.

## Deployment
The production source package is `White_Sands_Live_Project_v3.zip` from the project conversation. Its contents must be placed at the repository root, with `index.html` at the top level. Do not upload the ZIP alone and expect GitHub Pages to unpack it.

After committing the website files, enable GitHub Pages in **Settings → Pages**, selecting **Deploy from a branch**, `main`, and `/(root)`.

Expected address after successful deployment:
https://brookehoward2008-droid.github.io/see-america-white-sands/

This address is a deployment target, not a verified live URL.
